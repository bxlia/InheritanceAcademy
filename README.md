# InheritanceAcademy

Крупный учебный проект (Solution) на C#, в котором детально разбираются механизмы ООП: сложные цепочки наследования, абстрактные классы, интерфейсы-контракты, обработка ошибок, графическая отрисовка в консоли и работа с файловыми потоками.

---

## Подробный разбор модулей и файлов

### 1. Модуль AbstractBaseClass (Иерархия транспорта)
Проект показывает разделение сущностей по логике **«является» (is-a)**:
* **Базовый абстрактный класс (`Vehicle`):** Имеет private-поле `speed` и абстрактный метод `public abstract void Move();` без реализации. Создать объект этого класса через `new` нельзя.
* **Промежуточные слои:** Классы делятся по средам обитания на `AirVehicle`, `GroundVehicle` и `WaterVehicle`. Они наследуют базовый класс, но тоже остаются абстрактными.
* **Дальнейшее ветвление наземного транспорта:** Выделяются абстрактные подклассы для движения по рельсам (`OnRaills`) и по дорогам (`OnRoad`).
* **Финальные конкретные классы:** `Car`, `Bike`, `Train` и `Tramwai` завершают цепочку наземного транспорта. Они переопределяют метод `Move()` через ключевое слово `override` для вывода уникального поведения. Например, `Train` пишет про большие расстояния, а `Tramwai` — про поездки по городу.

### 2. Модуль Academy (Свойства, Сериализация и Фабрика)
Управление списком людей в академии с сохранением их данных в файл и восстановлением структуры в памяти:
* **Инкапсуляция и Конструкторы:** Классы `Student`, `Teacher`, `Human` и `Specialist` используют автосвойства для полей данных. Конструкторы дочерних классов вызывают базовый конструктор через ключевое слово `: base(...)` и логируют хэш-коды объектов для контроля за выделением памяти. В классе `Student` дополнительно реализованы перегруженные конструкторы копирования.
* **Полиморфный ввод (`Init`):** Каждый класс переопределяет метод `public override Human Init(string[] values)`, который принимает массив считанных строк, передает базовые поля наверх через `base.Init(values)` и самостоятельно парсит свои специфичные поля через `Convert`.
* **Текстовое и файловое представление:** Переопределены методы `ToString()` с выравниванием по правому краю `PadRight(12)` для красивой табличной печати в консоль. Метод `ToFileString()` подготавливает строку в формате CSV с разделителями-запятыми для записи на диск.
* **Потоковый менеджер (`Streamer`):** Читает CSV-файл с помощью `StreamReader`. Метод `Load` меняет рабочую директорию проекта через `Directory.SetCurrentDirectory("..\\..")`, построчно читает файл, режет данные через `.Split(":,;".ToCharArray())` и полиморфно восстанавливает объекты через `factory.Create().Init(values)`.
* **Фабрика объектов (`Factory`):** Метод `Create(string type)` использует конструкцию `switch` и операторы `nameof`. На основе текстовой метки из файла он создает нужный объект в куче и возвращает общую ссылку на тип `Human`.

### 3. Модуль Geometry (Консольный графический движок WinForms)
Математический расчет и физическая отрисовка двумерных фигур прямо поверх стандартного окна консоли Windows через контекст GDI+.

* **Интерфейсы-контракты:** Все методы внутри интерфейсов по умолчанию являются абстрактными и публичными:
  * `IHaveHeight` — контракт на получение высоты фигуры и её отрисовку (`double GetHeight(); void DrawHeight(...);`).
  * `IHaveDiameter` — контракт для круглых фигур (`double GetDiameter();`).
  * `IHaveDiagonal` — контракт для четырехугольников с диагоналями.
* **`Shape.cs` (Базовый абстрактный класс фигур):** Содержит статические ограничения размеров окна (`MIN_START_X = 100`, `MAX_START_Y = 700`) и свойства координат с тернарными проверками в блоке `set` для жесткой фильтрации входящих значений.
* **`Circle.cs` (Круг):** Вычисляет диаметр (`2 * Radius`), площадь через `Math.PI * Math.Pow` и периметр. Отрисовывает контур методом `DrawEllipse`, а также самостоятельно чертит линию своего диаметра прямо в центр окружности.
* **`Parallelogram.cs` (Параллелограмм):** Защищает свойство угла через остаток от деления (`value % 180`). Высота рассчитывается тригонометрически: `side * Math.Sin(angle * Math.PI / 180)`. Отрисовка идет через `DrawPolygon` по массиву 4-х точек с учетом вычисленного математического смещения `offset` по оси X.
* **`Triangle.cs` (Иерархия треугольников):** Внедряет интерфейс `IHaveHeight`. Класс `EquilateralTriangle` (равносторонний) считает высоту по теореме Пифагора и рисует контур по трем точкам. `IsoscelesTriangle` считает параметры на основе основания и боковой стороны. `RightTriangle` (прямоугольный) высчитывает свойство `Hypotenuse` и опускает высоту к ней.
* **`Rectangle.cs` (Прямоугольники и Квадраты):** Реализует `IHaveDiagonal`. Метод `GetDiagonal()` рассчитывает длину диагонали через корень суммы квадратов сторон, а `DrawDiagonal` проводит линию через фигуру. `Square` наследует прямоугольник, передавая сторону дважды в базовый конструктор.
* **`Program.cs` (Точка входа и отрисовка):** Использует **P/Invoke** и атрибут `[DllImport("kernel32.dll")]` для вызова нативной функции `GetConsoleWindow()`. Получает дескриптор окна `IntPtr hwnd`, создает контекст `Graphics.FromHwnd(hwnd)` и пачку тестовых фигур разных цветов, вызывая для каждой полиморфный метод `Info(e)`.

### 4. Модуль Exceptions (Математическая обработка)
* **`Program.cs` (Факториал больших чисел):** Программа рассчитывает факториал числа, введенного пользователем. Чтобы избежать арифметического переполнения стека и памяти при расчете огромных чисел, для хранения результата используется безлимитный тип данных `BigInteger` из пространства `System.Numerics`.

### 5. Модуль Inheritance (Базовое наследование)
* Модуль для проверки синтаксиса передачи параметров из конструктора дочернего класса в конструктор родительского класса с помощью ключевого слова `base`.

## Запуск проекта
1. Откройте файл решения `InheritanceAcademy.sln` в Visual Studio.
2. Для сборки графического модуля `Geometry` убедитесь, что в проекте подключены системные ссылки на `System.Drawing` и `System.Windows.Forms`.
3. Кликните правой кнопкой на нужный проект (например, `Academy` или `Geometry`) и выберите **Set as Startup Project**.
4. Нажмите `F5`. Программа скомпилируется в промежуточный **ILcode**, который виртуальная машина **CLR** выполнит на компьютере.
